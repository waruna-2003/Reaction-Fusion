# Experiment protocol

- Compare ReactionFusion against clearly implemented reaction-filtering baselines.
- Use identical group-aware dataset splits for BiLSTM, GRU, mBERT, and XLM-R.
- Fix and record seeds, preprocessing, hyperparameters, label version, and code commit.
- Report class support, macro/weighted F1, precision, recall, accuracy, and confusion matrices.
- Evaluate final sentiment quality on an independently human-annotated test set.
- Include ablations for ambiguous reactions, confidence thresholds, and soft versus hard labels.
